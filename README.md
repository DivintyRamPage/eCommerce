
## Про проєкт

Це повноцінний цикл покупки: каталог → кошик → оформлення замовлення, плюс авторизація та список обраного.

**Iнструменти:** бекенд (Node.js + Express + JSON-файлова база) розроблявся з допомогою AI як навчальний інструмент для практики роботи з реальним API. Весь фронтенд — React, React Router, Axios — написаний самостійно.

## Стек

- React 18 + Vite
- React Router
- Axios
- Чистий CSS (без UI-бібліотек)

## Що реалізовано

- 🛍️ Каталог товарів з фільтром по категоріях
- 🔐 Реєстрація та вхід (JWT-токен, збереження сесії в `localStorage`)
- 🛒 Кошик: додавання, зміна кількості, видалення — з миттєвим оновленням лічильника в хедері
- ❤️ Список обраного (wishlist)
- 📦 Оформлення замовлення та історія замовлень
- 📱 Адаптивна верстка

## Запуск локально

1. Переконайся, що [бекенд](../ecommerce-backend/README.md) вже запущений на `http://localhost:4000`.
2. Встанови залежності:
   ```bash
   npm install
   ```
3. Запусти дев-сервер:
   ```bash
   npm run dev
   ```
4. Відкрий `http://localhost:5173`.

Локально запити на `/api/...` автоматично йдуть на бекенд через proxy в `vite.config.js` — окремо нічого налаштовувати не треба.

## Структура проєкту

```
src/
├── api/                  # axios-інстанс (за наявності)
├── components/
│   └── Header.jsx        # хедер з навігацією, пошуком, лічильниками кошика/обраного
├── forms/
│   ├── LoginForm.jsx
│   └── SignUpForm.jsx
├── pages/
│   ├── home/              # каталог, категорії, картки товарів
│   ├── checkout/           # кошик + оформлення замовлення
│   ├── orders/             # історія замовлень
│   └── wishlist/           # обране
├── utils/
│   └── money.js           # форматування цін
├── App.jsx                # маршрути, глобальний стан (юзер, кошик)
└── main.jsx
```

## Архітектурні рішення

- **Стан юзера і кошика піднятий в `App.jsx`** — єдине джерело правди, щоб хедер і всі сторінки бачили однакові, актуальні дані без дублювання запитів.
- **Сторінки розбиті на контейнер + презентаційні компоненти** (наприклад, `CheckoutPage` + `CartItem`/`CartSummary`) — логіка запитів окремо від чистого рендеру.
- **Захищені маршрути** (кошик, обране, замовлення) перевіряють `isLoggedIn` і показують заклик увійти замість помилки.


## Відомі обмеження

- Фото товарів — плейсхолдери з [picsum.photos](https://picsum.photos), не пов'язані тематично з конкретним товаром.
- Оплата не реалізована — це навчальний макет, реальні платежі не проходять.
